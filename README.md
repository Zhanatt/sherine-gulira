## Анкета → Google Таблица
Пока `CONFIG.rsvpEndpoint` пустой, работает ДЕМО: форма показывает «Рахмат!», но ничего не отправляет.
Перед рассылкой гостям: таблица → Расширения → Apps Script → вставить `google-apps-script/Code.gs`
→ Развернуть как веб-приложение (доступ: Все) → URL вписать в `CONFIG.rsvpEndpoint`.

При правке CSS/JS менять `?v=` у `style.css` и `app.js` в `index.html`.
`sherine.html` — отдельный ранний макет (артефакт claude.ai), в репозиторий не входит.
